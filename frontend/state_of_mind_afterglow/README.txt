STATE OF MIND — AFTERGLOW
-------------------------
A minimal, full-screen prototype built around the supplied digital flower animation.

RUN IT
1. Extract this ZIP.
2. Open the state_of_mind_afterglow folder in VS Code.
3. Open index.html with Live Server.
   If Live Server is not installed, double-click index.html in File Explorer.
4. Keep the assets folder beside index.html. It contains the trimmed video.

DESIGN
- Original uploaded animation, trimmed before the video-player controls appear.
- Full-screen black / plum background and restrained rose-lilac color grading.
- Intro copy fades away; five mood choices fade in over the same scene.
- Responsive mood cards and a simple selected-mood state.

NOT CONNECTED YET
Mood choices currently show prototype copy only. Backend/API integration with Flask should be added after the visual direction is approved.
